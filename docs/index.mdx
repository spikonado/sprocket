Sprocket works in a folder on your computer. It edits code, runs commands, browses the web, and designs schematics and circuit boards in KiCad. It can also buy parts with your approval.

<Warning>The agent runs as your user on your real files. Its commands aren't sandboxed.</Warning>

<Steps>
  <Step title="Install Sprocket">
    Download and open the desktop app for macOS, Windows, or Linux from the [latest release](https://github.com/spikonado/sprocket/releases/latest).

    Or run the web app with [Node.js](https://nodejs.org/) 20.11 or newer:

    ```sh
    npx usesprocket --web
    ```

    Both use a local server on your machine. See [Install](/install) for supported platforms, updates, and release channels.

  </Step>
  <Step title="Sign in">
    Sign in with your Sprocket account. The Free plan includes monthly AI usage. You don't need an API key.
  </Step>
  <Step title="Open a project">
    Choose **Add project → Local folder** and pick a folder. Clones with the same git `origin` remote share a thread list.
  </Step>
  <Step title="Send a task">
    Describe what you want in the composer, then press Enter or click the send button. For example:

    ```text
    Find out why the tests in this repo fail and fix them.
    ```

    The agent replies and shows its tool calls in the thread. Press **Stop generation** to end a run early.

  </Step>
</Steps>

## Run a task from your terminal

Run these commands in your project folder:

```sh
npm install -g usesprocket
sprocket login
sprocket run "Fix the failing tests"
```

`sprocket run` prints the final answer to stdout. See the [CLI reference](/reference/cli) for options.
