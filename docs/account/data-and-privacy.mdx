---
title: Data and privacy
description: Where Sprocket stores your data, how it handles secrets, and how to request deletion.
---

The agent reads and edits project files on your computer. Sprocket syncs thread content, artifacts, and attachments to the cloud. Model providers also receive the context sent with model requests, which can include file contents and tool output.

## Encryption

- Connections to Sprocket's hosted services use TLS.
- Threads, artifacts, and account data are stored in [Convex](https://www.convex.dev/security), encrypted at rest with AES-256.
- Attachments are stored in [Cloudflare R2](https://developers.cloudflare.com/r2/reference/data-security/), encrypted at rest with AES-256.
- Saved provider API keys, Claude sign-ins, and GitHub tokens use [WorkOS Vault](https://workos.com/docs/vault). Vault encrypts each stored secret with a unique encryption key.
- ChatGPT sign-in credentials are stored on your computer.

## Secrets in threads

Before syncing transcript text to Sprocket's servers, Sprocket replaces detected secrets with placeholders like `[redacted:openai-key]`. It looks for known key formats, passwords in URLs, and random-looking tokens. It can miss secrets, and this redaction does not prevent secrets from reaching model providers or tools. Avoid putting secrets in messages or tool output.

## Usage analytics

Sprocket sends usage events, such as token counts and run durations, to [PostHog](https://posthog.com). The app also identifies signed-in users by user ID and email and captures errors. Session replay is configured to mask text and inputs.

## Deleting data

You can delete threads, artifacts, and saved keys. Deleting an artifact also deletes its bound local files. Each day, Sprocket deletes cloud-stored threads that have been inactive for 180 days, along with their subagents. It skips deletion if the thread or any of its subagents has an active run.

For privacy questions or account deletion requests, email [privacy@spikonado.com](mailto:privacy@spikonado.com).
