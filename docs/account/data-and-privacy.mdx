## Stored on Sprocket's servers

- Threads and their transcripts, including tool output.
- Artifact contents.
- Attachments. Sprocket deletes them 7 days after a thread's last message.
- Files the agent can't parse on your computer. Sprocket uploads them for a short time to parse them.
- Your settings and UI preferences.
- Each machine's name, hostname, platform, architecture, and Sprocket version.
- Usage and purchase records.
- API keys, GitHub tokens saved by older versions of Sprocket, and Claude sign-in tokens, encrypted in [WorkOS Vault](https://workos.com/vault).

## Secrets in threads

Before your computer uploads a prompt, reply, tool call, tool output, or context summary, Sprocket replaces secrets in it with placeholders like `[redacted:openai-key]`. It looks for known key formats, private keys, passwords in URLs and long random strings.

- Model reasoning is uploaded as the provider returned it, because providers need it unchanged to continue the conversation.
- Web search and scrape requests are uploaded as written, because Sprocket's servers run them.
- Your `AGENTS.md` files and skill descriptions are uploaded as written, because the agent needs them in every message.
- Answers the agent gives to its subagents' questions are uploaded as written, so a subagent can use a key it asked for.
- While the agent works on the message that brought in a secret, it uses the real value. Later messages, and work that resumes after Sprocket restarts, see the placeholders, so the agent can't read a key you pasted in an earlier message.

## Kept on your computer

- Your project files. The agent reads and edits them in place.
- Your Sprocket sign-in, in the OS keyring or a private file. See [Credentials](/reference/configuration#credentials).
- ChatGPT and Muse sign-ins.
- Whether GitHub is on, and your GitHub and Vercel CLI sign-ins.
- Connectors and the tools Sprocket installs.
- A cache of thread transcripts.
- Full command output logs from agent runs.

## Usage analytics

Sprocket sends usage numbers to [PostHog](https://posthog.com), such as token counts, cost, latency, which tools the agent calls, and how runs end. These events are tied to your account. It doesn't send your prompts, the agent's replies, tool input or output, or file contents. Error reports include error messages. Session replays mask all text and inputs. Spikonado doesn't sell your data.

## Deleting data

You can delete artifacts, remove saved API keys and subscriptions, and remove projects from your list. Deleting an artifact also deletes its file in your project. To delete threads or your account, email [aarav@spikonado.com](mailto:aarav@spikonado.com).
