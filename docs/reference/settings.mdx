---
title: Settings
description: Every page and option in Sprocket's settings, including general behavior, account, AI usage, providers, keys, version control, connectors, and payments.
---

Open settings from the sidebar. Switch between light and dark mode with the button at the top of the sidebar.

## General

| Setting                                                                 | Default |
| ----------------------------------------------------------------------- | ------- |
| Automatically name threads                                              | On      |
| Continue agents automatically after restarts and crashes                | On      |
| Settle threads when their PRs merge                                     | Off     |
| Share anonymous conversation data to help improve Sprocket for everyone | On      |

## Account

Your name and email, your plan's usage and reset time, your credit pack balance, and **Sign Out**. See [Plans and usage](/account/plans-and-usage).

## AI Usage

Cost, tokens, cache hit rate, and model calls over the last 24 hours, 7 days, 30 days, 12 weeks, or 12 months, with a chart and a per-model table. Each model has a switch to include or exclude it from the totals.

## Providers

The order in which Sprocket tries providers, and which ones are on. See [Provider order and fallback](/use/models-and-providers#provider-order-and-fallback).

## BYOK/BYOS

Your API keys and subscription sign-ins. See [Providers](/use/models-and-providers#providers).

## Version Control

| Setting                                      | Default |
| -------------------------------------------- | ------- |
| Add Sprocket as a co-author on agent commits | On      |

## Connectors

Install, update, and uninstall connectors on the computer running Sprocket. See [Hardware](/use/hardware).

GitHub and Vercel are connectors too. Sprocket installs their CLIs, and you sign in to each from its card. The GitHub card also has switches to turn off GitHub or one of its hosts. See [GitHub](/use/github) and [Vercel](/use/vercel).

## Payments

Saved cards and purchase history. See [Purchases](/use/purchases).
