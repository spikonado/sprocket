---
title: Keyboard shortcuts
description: Keyboard shortcuts in the Sprocket app for threads, the composer, the project picker, and the file tree.
---

On macOS, use ⌘ where this page says Ctrl.

## Threads

| Keys          | Action                                       |
| ------------- | -------------------------------------------- |
| Alt+N         | New thread                                   |
| Alt+↑ / Alt+↓ | Previous or next thread, outside text fields |

## Composer

| Keys         | Action                                                 |
| ------------ | ------------------------------------------------------ |
| Enter        | Send                                                   |
| Shift+Enter  | New line                                               |
| `@`          | Mention a file or folder                               |
| `$`          | Mention a skill                                        |
| `/`          | Mention a skill that loads only when you type its name |
| ↑ / ↓        | Move through the mention menu                          |
| Enter or Tab | Pick a mention                                         |
| Esc          | Close the menu                                         |

On touch screens, Enter adds a new line instead of sending.

## Project picker

| Keys       | Action                  |
| ---------- | ----------------------- |
| ↑ / ↓      | Move through folders    |
| Enter      | Open the folder         |
| Backspace  | Go to the parent folder |
| Ctrl+Enter | Add the project         |

## Files

| Keys   | Action       |
| ------ | ------------ |
| Ctrl+F | Search files |
