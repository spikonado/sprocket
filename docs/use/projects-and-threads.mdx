## Projects

A project groups threads for a repository or local folder. Open a folder with **Add project → Local folder**, or run `sprocket path/to/folder` in your terminal.

### Clone or create a GitHub repository

**Add project** also lets you clone or create a repository:

- **Clone a repo** accepts `owner/repo` or a git URL.
- **New GitHub repo** creates a public or private repository on your github.com account.

Choose a destination folder. Sprocket clones into a new subfolder named after the repository. GitHub authentication uses your sign-in from **Settings → Connectors**. Creating a repository needs a token with permission to do so.

Sprocket identifies a project by its git `origin` remote. Every clone and worktree of the same repository shares one project and one thread list, even on different machines. A repository without an `origin` remote, or a folder outside git, is identified by its folder name, so two such folders with the same name share a project.

When you or the agent add an `origin` remote to a project that didn't have one, Sprocket moves the project's threads and artifacts to the remote's project. Threads from other folders with the same name move too, since they shared the project.

Switch projects from the project menu. **Remove** takes a project off the list without touching its files.

## Threads

A thread is one conversation with the agent. The sidebar groups threads into **Unsettled** and **Settled Threads**.

Open a thread's menu to settle or unsettle it, rename it, regenerate its title, move it to another project, copy its ID, or delete it. You can't settle, move, or delete a thread while it or its subagents are running. Deleting a thread also deletes its subagents and attachments, and you can't undo it.

Sprocket names new threads for you unless you turn this off in [Settings → General](/reference/configuration#general). It can also [settle threads when their pull requests merge](/use/github#pull-requests-in-threads).

### Search threads

Type in the search box above the thread list to show only threads whose titles match. A thread also shows when one of its subagents' titles matches. Settled matches load when you open **Settled Threads**. Press Escape to clear the search.

### Send messages

On desktop, press Enter to send and Shift+Enter for a new line. On touch devices, use the send button. Wait for the current run to end before sending another message. You can answer the agent's questions during a run.

Add context to a message:

| To add                | Do this                                                                                        |
| --------------------- | ---------------------------------------------------------------------------------------------- |
| Files                 | Click **Attach files**, drag them in, or paste them. Images show a preview.                    |
| A file or folder path | Type `@` and pick from the workspace.                                                          |
| A skill               | Type `$` or `/` followed by the skill name. See [Skills](/use/instructions-and-skills#skills). |

### Stop and continue

**Stop generation** ends the current run. Each running command also has its own **Stop command** button.

If a run fails or the server restarts, **Continue working** resumes the thread. Sprocket also resumes interrupted runs automatically after a restart or crash, unless you turn this off in [Settings → General](/reference/configuration#general).

### Read the agent's work

Work blocks summarize the agent's activity. Open a block to inspect tool calls, then click a row for details. Reasoning stays collapsed until you open it. Use **Show earlier** to load older items in a long block.

### Subagents

The agent can delegate tasks to [subagents](/use/agent-tools#subagents). Each has its own thread under the parent in the sidebar.

## Workspace tabs and panels

Each thread starts with a **Thread** tab for the conversation and composer. You can't close this tab. Tabs opened before your first message stay with the new thread.

Use **New tab** to open a view, or **Split right** and **Split down** to add panels. Drag a divider to resize panels. Each thread keeps its own tabs and panel sizes until you reload the app.

New tabs offer three views:

- **Artifacts** shows files the agent linked to the project. See [Artifacts](#artifacts).
- **Files** is a file tree where you can search, create, rename, delete, and edit files. The editor asks before it discards unsaved changes.
- **Browser** shows the browser the agent controls.

### Artifacts

An artifact is a file the agent linked to the project for you to view. Edits to the file show up in the artifact. Sprocket chooses how to render it from its title, which defaults to the file name:

| Title ends with   | Renders as                                                               |
| ----------------- | ------------------------------------------------------------------------ |
| `.html` or `.htm` | A web page                                                               |
| `.jsx`            | A React component                                                        |
| `.render.json`    | A [json-render](https://json-render.dev) spec using the app's components |
| `.wiring.json`    | A [wiring diagram](/use/hardware#wiring-diagrams)                        |
| Anything else     | Markdown                                                                 |

### Rich replies

Agent replies support GitHub-flavored Markdown, HTML and React visuals, Mermaid diagrams, math, and artifact cards. [KiCad cards](/use/hardware#view-designs) open schematic, PCB, and 3D views. Code blocks have syntax highlighting and a copy button.

### Usage per thread

The **AI usage** button shows the thread's estimated API cost, with an option to include subagents. See [Plans and usage](/account/plans-and-usage#track-usage) for how these estimates differ from your bill.
