## KiCad connector

The KiCad connector lets the agent create and edit schematics and boards, run electrical and design rule checks, and export Gerbers, renders, and bills of materials. It includes KiCad, its Python API, and libraries. Routing tools are included except on Windows Arm.

<Steps>
	<Step title="Open Settings → Connectors">
		Do this in Sprocket on the computer that will run the agent. Connectors install on that
		computer.
	</Step>
	<Step title="Install KiCad">
		Click **Install**. Allow 10 GiB of free disk space if the connector needs to download KiCad.
	</Step>
</Steps>

The connector runs on macOS on Apple silicon and Intel, Windows on x64 and Arm, and Linux x64. It uses an existing KiCad installation if it finds version 10.99 or newer with API server support. Otherwise it downloads a KiCad nightly build. If you uninstall or downgrade the KiCad installation it uses, reinstall the connector.

When a connector update is ready, **Settings → Connectors** shows an **Update** button.

<Info>Connectors are experimental.</Info>

## View designs

When the agent works on a KiCad project, it can add a project card to its reply. The card opens the project's schematics. If the project has a board, pick **PCB** to see the board or **3D** to see it in 3D. A `.kicad_pcb` file opened from the file browser shows the board with **2D** and **3D** views.

In the board view:

- Drag to pan. Scroll or pinch to zoom at the pointer.
- Use **Layers** to show or hide board layers.
- Zoom in on a pad to see its number and net name.
- **Fit board** zooms to the whole board. **Flip board** shows the back side, mirrored, with the back layers on top.
- Click an item to select it and see its reference, value, net, layer, and position. Selecting a pad also shows its footprint. Press Escape or click empty space to clear the selection.
- When the board file changes, the view reloads and keeps your zoom and layers. The selection clears.

In the 3D view:

- Drag to orbit. Right-drag, middle-drag, or Shift-drag to pan. Scroll or pinch to zoom at the pointer.
- The board, copper, solder mask, silkscreen, and holes show right away. Component models load in the background and need the KiCad connector.
- **Components** shows or hides the component models. **Fit board** fits the whole board in view. **Flip board** turns the board over.
- When the board file changes, the board updates at the same camera angle.

The board view doesn't draw images or barcodes yet.

## Wiring diagrams

For projects built from modules and dev boards, the agent can save a wiring diagram as a `.wiring.json` artifact. You don't need the KiCad connector to view it.

- Pick a build step to see its wires, with earlier wires faded, or pick **Show all**.
- Click a part to focus its connections. Click it again to go back to the steps.
- Tick off wires in the checklist as you connect them. Hover over a row to highlight its wire.
- The parts list includes photos and purchase links when available.

Sprocket checks the diagram for invalid parts and pins, some shorts, and voltage conflicts using pin names and the voltage information in the file. It also warns about steps with more than 6 wires. The agent receives validation results when it uses the patch or artifact tools. These checks don't verify the physical circuit or individual pin tolerances.

If a wire can't find a free path, it shows as a dashed straight line with a warning. Use the checklist for that wire.

In a narrow workspace panel, the diagram shrinks to fit. Open it fullscreen to read the pin names.

## Hardware skills

Sprocket's [built-in skills](/use/instructions-and-skills#built-in-skills) cover these hardware tasks:

- `designing-pcbs` for schematics, boards, and exports.
- `selecting-hardware-parts` for picking parts and suppliers and writing a BOM.
- `designing-wiring-diagram` for projects built from modules and dev boards rather than a custom PCB.

To order the parts, see [Purchases](/use/purchases).
