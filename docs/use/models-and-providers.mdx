## Choose a model

Pick a model in the composer's model menu. Use the company logos to switch model groups. Choose a reasoning level if the model supports it. The **Fast** switch uses a faster service tier where available. Sprocket saves these choices for each thread.

The model list updates from Sprocket's servers. To list models in your terminal:

```sh
sprocket run --list-models
```

## Providers

A provider handles model requests. Spikonado, Sprocket's own provider, is on by default and uses your plan's [AI usage](/account/plans-and-usage). Other providers use your keys or subscriptions and don't count against your Sprocket AI usage.

| Provider               | How to connect                                                                                      |
| ---------------------- | --------------------------------------------------------------------------------------------------- |
| Spikonado              | On by default                                                                                       |
| OpenAI API             | API key                                                                                             |
| ChatGPT Subscription   | Sign in with ChatGPT. You can add more than one account. Usage counts against your Codex allowance. |
| Claude Subscription    | Sign in with Claude through Claude Code. Sprocket can install Claude Code for you.                  |
| Anthropic API          | API key                                                                                             |
| Vercel AI Gateway      | API key                                                                                             |
| OpenRouter             | API key                                                                                             |
| OpenCode               | API key                                                                                             |
| OpenCode Go            | API key                                                                                             |
| Morph                  | API key                                                                                             |
| Gemini API             | API key from [Google AI Studio](https://aistudio.google.com/apikey)                                 |
| Google Vertex AI       | Service account JSON key. See [Google Vertex AI](#google-vertex-ai).                                |
| Muse Code Subscription | Sign in with Muse through the Muse CLI. Sprocket can install the Muse CLI for you.                  |

Add keys and subscriptions in **Settings → Providers**.

### Google Vertex AI

Vertex AI serves Claude and Gemini models from your Google Cloud project and bills that project. To connect it:

1. In the Google Cloud console, enable the Vertex AI API and the Claude models you want in Model Garden.
2. Create a service account with the **Vertex AI User** role.
3. Create a JSON key for it and paste the whole file into the Google Vertex AI card.

Sprocket sends requests to Vertex's global endpoint.

### Provider order and fallback

In **Settings → Providers**, drag providers into the order you want and turn each on or off. At least one provider must stay on.

New providers go at the end of the list. Reconnecting a provider keeps its position. Removing a provider deletes its saved credentials. You can't remove Spikonado, but you can turn it off.

Sprocket starts each run with the first enabled provider that serves the model. It retries transient server errors before trying other enabled providers that serve the same model, in your saved order. Rate limits also trigger fallback.

## Context handoff

Near the model's context limit, Sprocket asks it to write a handoff note and continues the thread in a fresh context. Changing providers or switching to a model from another vendor also prompts a handoff. Automatic provider fallback during a run reuses the conversation instead of writing a handoff note.
