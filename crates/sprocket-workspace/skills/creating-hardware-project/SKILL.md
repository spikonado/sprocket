---
name: creating-hardware-project
description: 'Read this before starting to work on hardware projects.'
---

- Only use `$kicad-schematic-authoring` when a user requests for a PCB to be designed.
- A PCB isn't required for most projects.
- Create hardware project docs using `$hardware-project-docs`.
- When the project is just a PCB and nothing else, you only need to create the BOM document from `$hardware-project-docs` and none of the other docs.
- After getting confirmation on the BOM from `$hardware-project-docs`, order the parts from online stores using the tools and skills given to you.
